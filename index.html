設定您的 Gemini API 金鑰

本輔導系統完全免費，語音分析與轉譯功能直接連線至 Google 官方 Gemini 模型。為了保護學生隱私，所有資料與金鑰均儲存在您個人的瀏覽器中，不會上傳到任何第三方伺服器。

如何取得免費 Gemini API 金鑰？

  1. 點擊前往 Google AI Studio 官網 。
  2. 登入您的 Google 帳號。
  3. 點擊左上角的 「Get API key」 按鈕。
  4. 點擊 「Create API key」 並建立一個新金鑰，將其複製起來貼到下方。
